Overview : 
This project explores text classification using the 20 Newsgroups dataset and machine learning techniques from scikit-learn.
The objective is to classify text documents into their corresponding newsgroup categories and investigate how preprocessing methods, training dataset size, and model selection affect classification performance.

Objectives :
Explore and preprocess the 20 Newsgroups dataset.
Build a baseline classifier using Multinomial Naive Bayes and CountVectorizer.
Evaluate the impact of different training dataset sizes (10%, 30%, 50%, and 100%).
Compare Multinomial Naive Bayes, Linear Support Vector Classification (Linear SVM), and Logistic Regression using TF-IDF features.
Evaluate performance using accuracy, macro precision, macro recall, and macro F1-score.
Test the selected model on manually written text examples from different genres.

Dataset : 
The project uses the 20 Newsgroups dataset provided by scikit-learn.
The dataset contains text documents from 20 newsgroup categories. Headers, footers, and quoted text are removed during dataset loading to focus on document content.
The dataset is loaded directly through fetch_20newsgroups, so a separate dataset download is not required.

Methodology : 
1. Text preprocessing
Convert text to lowercase.
Tokenize text using NLTK.
Remove punctuation and non-alphabetic tokens.
Remove English stopwords.
Apply WordNet lemmatization.
2. Baseline model
Multinomial Naive Bayes is trained using word-count features generated by CountVectorizer.
3. Training dataset size experiment
The Naive Bayes classifier is evaluated using 10%, 30%, 50%, and 100% of the training data. Performance is compared using accuracy and macro F1-score.
4. Model comparison
Three classifiers are compared using TF-IDF features:
Multinomial Naive Bayes
Linear Support Vector Classification (Linear SVM)
Logistic Regression
The model with the highest macro F1-score on the test set is selected for further evaluation.
5. Evaluation and manual examples
The selected model is evaluated using a classification report, including per-class precision, recall, and F1-score. Six manually written examples are also used to explore predictions on different types of text.
